# 【职工大会】我院第五届职代会暨第七届工代会第二次会议顺利召开

> 更新时间：2026-09-16 (UTC+8)

//

2022年1月19日下午，我院于第二学术报告厅召开第五届职代会暨第七届工代会第二次会议。大会由党委副书记江耀睦同志主持，来自全院各科室的正式代表123人参加了会议。全院中层干部在第一学术报告厅、大会议室收看会议实况视频直播。

大会在庄严的国歌声中拉开了序幕。与会代表听取了陈永松院长所作的《汕头大学医学院第一附属医院2021年工作报告及2022年工作计划》、《汕头大学医学院第一附属医院“十四五”规划纲要（草案）》的报告，以及《汕头大学医学院第一附属医院2021年度财务工作报告及2022年预算草案》（书面）。医院工作报告总结了医院过去一年的主要工作，充分肯定医院取得的成绩；“十四五”规划报告客观总结了医院“十三五”工作完成情况和取得的优异成绩，系统地描绘了医院未来五年发展蓝图，定下医院未来发展的方向。经过审议后，大会通过了各项工作报告，圆满完成了会议的各项预定议程。

大会认为，2021年医院以习近平新时代中国特色社会主义思想和党的十九大、十九届五中、六中全会精神为指引，在上级党委和主管部门的正确领导下，在全体干部职工的共同努力下，以向“质量效益”、“精细管理”方式转变为导向，以“公立医院绩效考核”和“三甲复评”为抓手，实现了医院运营指标总体向好。2022年我院将以习近平新时代中国特色社会主义思想为指导，贯彻落实《“健康中国 2030”规划纲要》的精神，按照广东省、汕头市政府和汕头大学决策部署，围绕建设健康广东、健康汕头目标，扎实推进我院“十四五”规划实施，做到综合救治能力、应急处置能力、公共卫生防控能力、科研教学能力协同发展，兼顾医教研融合与产学研结合，力争走向“体系创新、技术创新、模式创新、管理创新”的医院高质量发展之路。

2022年是实施“十四五”规划承上启下的关键之年。大会号召全体代表以习近平新时代中国特色社会主义思想为指导，不忘初心，牢记使命，秉持以人民为中心的发展思想，坚定不移落实医院发展战略，全面塑造发展新优势；坚定不移推动医院文化建设，促进医院和谐发展，为实现健康中国、平安中国、幸福中国贡献智慧和力量。
