# 东阳的骨科患者有福了！全市首个医学院士工作站落户人民医院

> 更新时间：2026-09-17 (UTC+8)

****

**
**

近日，东阳市人民医院骨科接诊到这样一位病人：52岁的王女士是罕见的“石骨症”病人，因骨折术后不愈合下地活动后引起固定钢板断裂骨折移位。

石骨症是一种罕见的家族性骨发育障碍性疾病，一旦发生骨折，手术难度极大，愈合困难。

据悉，为了造福广大骨伤科患者，今年5月10日东阳市人民医院成立了张英泽院士工作站。鉴于王女士病情的特殊性，张英泽院士再次来我院为患者亲自手术。

//骨科院士远飞千里上台手术//

近日，52岁的王女士患有罕见的石骨症，5个月前因外伤造成右股骨骨折，内固定手术后愈合缓慢，近日发现局部疼痛，经检查发现骨折移位，钢板断裂。医院安排王女士尽快入院，需要再次手术。

石骨症，顾名思义，全身的骨骼就像石头一样坚硬，骨髓腔明显缩小，甚至闭塞。石骨症为世界疑难杂症，治疗难点主要有以下几方面：1.石骨症患者骨密度广泛均匀增高硬化，髓腔狭窄甚至消失，扩髓困难，因此髓内固定不可行，需要选择钢板内固定；2.骨质硬度高，脆性大，普通刚性钻头极有可能无法钻透至对侧皮质，甚至发生钻头断裂残留在骨内或造成其他部位的骨折，进一步增加手术难度；3.骨折固定后，患者受外力时再发骨折或内固定物断裂的可能性大；4.石骨症患者髓内造血功能差，骨折断端血运差，骨折断端愈合时间长，几月-几年的情况均有，极有可能发生骨折不愈合。

在这些难度之外，王女士由于是原骨折部位固定钢板断裂，手术还需要面临取出原先固定物的困难，很有可能发生螺钉无法取出或者断钉的情况，这又加大了手术难度。

医院骨科团队迅速召集全科室成员进行病例讨论，并请中国工程院院士张英泽教授远程会诊，根据王女士的特殊病情制定了详尽的手术方案：手术方案有两种：一是再次钢板内固定，手术相对简单；二是髓内钉固定，但手术因扩髓困难，有不成功的风险。决定分两步走，先进行右胫骨结节骨牵引术，待骨折复位后在进行内固定复位术。

（张英泽院士手术）

经过右胫骨结节骨牵引术后，12月6日下午，张英泽院士亲自从河北来到东阳，走上手术台为王女士手术。手术难度极大，手术做得比普通手术要艰难得多。经过三个多小时努力，顺利地取出了原固定钢板螺钉，并且扩髓成功，手术结果满意。

 
//全市首个医学院士工作站落户人民医院//

12月6日下午，张英泽院士做完石骨症手术外，又通过微创的方法完成了另一台高难度的手术，两台手术用时比预计少了2小时左右，现场的骨科医生通过观摩学习，获得不少手术经验。

晚上7时，张英泽院士刚忙完手术不久，就马不停蹄地和三个院区骨科和手外科医生进行座谈，为东阳市人民医院骨科未来的发展，给出了非常中肯地建议。从医生自身主动学习、科室目标制定及长远的规划、在医疗技术提高以及理论水平的提高都给出了切实可以的意见，最后，张院士还希望两家医院要进行定期交流，河北医科大学附属第三医院将会为东阳市人民医院的骨科医生学习和交流提供便利。

（座谈会现场）

“听完张院士给我们的发展规划，感觉工作更有方向和动力了。会上，骨科多位主任及年轻医生发言，表示将珍惜难得的培训计划，努力提升技术，并且主动要求前往学习和进修。

自今年5月10日东阳市人民医院张英泽院士专家工作站成立以来，张英泽院士第二次来我院为患者手术。

//
张英泽院士名声显赫，

是全国骨科权威
//

张英泽是中国工程院院士，河北医科大学教授，博士生导师，曾任河北医科大学副校长，附属第三医院院长。现任河北省骨科研究所所长，兼任中医师协会副会长、中华医学会骨科学分会主任委员，美国科罗拉多大学、华南理工大学等国内外6所大学的客座教授。近年来，张英泽院士一直致力于复杂骨折闭合复位微创固定的研究，是我国骨科创新与骨折微创治疗的首倡者，也是全国骨科创伤领军人。

（张英泽院士在我院授课）

东阳市人民医院骨科近年来来通过不断地努力和发展，目前已成为浙江省县级医学龙头学科，金华市重点学科，浙中骨科脊柱外科治疗中心。骨科团队拥有131张床位，29名主治医师职称以上的技术骨干，其中主任医师6名，副主任医师10名，金华市名医2名，金华市医坛新秀2名，东阳市名医1名，东阳市医界新秀1名，321人才1名；2017年成立浙江大学附属二院东阳工作站，在颈椎及颈髓创伤的急救及诊疗，以及颈椎病的手术方面达省内先进水平，2017年度脊柱微创手术椎间孔镜手术达100余台，椎体成形术手术350台左右，椎间孔镜、椎体成形术水平达到省内先进水平，全年手术量4200台。

这个已经相当强大的骨科，为什么还要建院士工作站呢？

（5月授牌仪式）

“向全国顶尖学科学习，为东阳百姓服务，这是我院提出的“六个一”战略的出发点和归宿”，骨科主任、金华市名医张永进说。

据悉，今年5月成立的张英泽院士专家工作站，是东阳市医疗领域首个院士工作站，该工作站的成立将为东阳市人民医院骨科的人才培养、基础科研、学科管理上提供帮扶，以专家下沉讲课、手术、手把手教学、进修培训等多种途径，提高诊治东阳老百姓骨科疑难复杂疾病的能力。
